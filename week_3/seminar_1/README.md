## Темы

Токенизация, специальные токены, маски, заполнение и обрезка; восстановление пропуска; классификация тональности и метрики; загрузка корпуса через Datasets Hub; NER; извлечение ответа из контекста; суммаризация и проверка фактов.

Используются `pipeline`, `AutoTokenizer` и `load_dataset`. Здесь применяются готовые модели; обучение через `Trainer` вынесено во второй семинар.

## Запуск

В Colab выберите T4 GPU и выполняйте ячейки сверху вниз. Все модели публичные, API-ключ не нужен. При первом запуске скачиваются веса. Если после установки библиотек появляется запрос на перезапуск, перезапустите сеанс и выполните ноутбук заново.

Для отдельного локального окружения: `pip install -r requirements.txt`, затем `jupyter lab`. Локальный вычислительный прогон отдельно не проверялся.
