## Темы

Классификация русских отзывов о кино; train/validation/test и удаление точных повторов; токенизация и динамическое заполнение; TF-IDF с логистической регрессией; новая классификационная голова; полное дообучение RuBERT-base через `Trainer`; выбор checkpoint по validation macro-F1; разбор ошибок, итоговая оценка и повторная загрузка модели.

## Запуск

Рекомендуется Colab с T4 GPU. Выполняйте ячейки сверху вниз. API-ключи не нужны. После обновления уже импортированных библиотек перезапустите сеанс и выполните ноутбук заново.

Основной режим: `SMOKE_RUN=False`, 9000 обучающих, 1000 валидационных и 600 тестовых отзывов; 3 эпохи, предел длины 256 токенов, batch size 16, learning rate 2e-5. `SMOKE_RUN=True` предназначен для быстрой диагностики и не воспроизводит приведённую ниже оценку качества.

Для отдельного локального окружения: `pip install -r requirements.txt`, затем `jupyter lab`. Локальное обучение отдельно не проверялось; на CPU оно будет медленнее.

## Проверенный эксперимент

Модель: `DeepPavlov/rubert-base-cased`. Корпус: `ai-forever/kinopoisk-sentiment-classification`. Ревизии зафиксированы в ноутбуке. Обучаются все параметры. TF-IDF получает те же доступные фрагменты текста; C выбирается по validation из 0,5, 1 и 2.

Первые 600 тестовых записей, использованных в предварительном опыте, исключены. Итоговая оценка выполнена на следующих 600 после фиксированного перемешивания. Checkpoint и C выбраны по validation до этой оценки.

| Модель | Validation accuracy | Validation macro-F1 | Test accuracy | Test macro-F1 |
| --- | ---: | ---: | ---: | ---: |
| TF-IDF + LogisticRegression | 0,6450 | 0,637991 | 0,640000 | 0,631499 |
| Дообученный RuBERT-base | 0,6640 | 0,665339 | 0,671667 | 0,666497 |

На новой тестовой части выигрыш BERT — 3,17 процентного пункта accuracy и 3,50 пункта macro-F1. Вывод относится к одному seed, этому корпусу и фрагментам до 256 токенов. На двух коротких оценочных фразах из дополнительной демонстрации модель ошибочно выбрала нейтральный класс.

Проверено 14 ноября 2026 года в Colab на Tesla T4: все 18 кодовых ячеек, 1689 шагов, 534,4 секунды обучения с промежуточными оценками и сохранением checkpoints. Проверены обновление весов головы и кодировщика, совпадение токенов и предсказанных классов после повторной загрузки на 8 validation-примерах. Две финальные ячейки дополнительно выполнены после исправления ложного предупреждения Transformers о токенизаторе.

В GitHub выводы очищены; выполненная версия доступна по ссылке Colab. Для нового независимого обучения начните с чистого ядра: повторный вызов `trainer.train()` на уже обученных весах меняет условия опыта.
