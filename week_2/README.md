## Локальный запуск

Требуется Python 3.11+; GPU не нужен.

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```

В Windows для активации: `.venv\Scripts\activate`.

Откройте основной ноутбук и выполняйте ячейки по порядку. Адрес OpenAI-совместимого API и ключ вводятся в скрытых полях либо передаются переменными окружения `NLP_API_BASE_URL` и `OPENAI_API_KEY`. В репозитории нет адреса сервера или ключа. Нужны собственные доступ и квота. Модель по умолчанию — `gpt-6-sol`; её доступность зависит от сервера.

Короткий режим `QUICK_RUN=True` проверен локально: 23 кодовые ячейки, 43 реальных вызова API без ошибок исполнения. Полный режим включается через `QUICK_RUN=False` и отдельно не проверялся. Сохранённые выводы очищены. Параметры temperature/top_p/top_k/seed в этой конфигурации серверу не передаются.

Локальные модели и альтернативные серверы упоминаются как дополнительные темы; отдельный дополнительный ноутбук в эту папку не входит.

## Домашнее задание 2. Промпты: извлечение, самосогласованность и атаки

[Открыть ноутбук](<Домашнее задание 2 — промпты, извлечение и атаки.ipynb>)

Три эксперимента с одинаковым протоколом (10 баллов):

- извлечение полей заявки в JSON: разбор ответа, метрики по полям, промпт без примеров и с примерами;
- самосогласованность: жадный ответ против голосования пяти сэмплов, точность и расход токенов;
- внедрение инструкций в отзывы: доля успешных атак для наивного и защищённого промпта.

По умолчанию работает через OpenAI-совместимый API, как семинар, — GPU не нужен. Локальная модель
`Qwen/Qwen2.5-1.5B-Instruct` (`NLP_BACKEND=local`, `pip install -r requirements-hw.txt`) имеет смысл
только с видеокартой или на Apple Silicon: на обычном CPU ноутбук займёт около часа.
