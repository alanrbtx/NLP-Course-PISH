## Семинар. Дообучение: Transformers, Datasets, PEFT и TRL

[Открыть ноутбук](<Семинар — дообучение с LoRA и DPO.ipynb>)

Обзор всего стека на маленькой модели `Qwen2.5-0.5B-Instruct` и задаче «команда голосовому помощнику → JSON»
(MASSIVE ru-RU, 200 обучающих примеров):

- **Transformers** — модель, токенизатор, шаблон диалога, генерация;
- **Datasets** — Alpaca в JSONL, `load_dataset("json")`, `map` в формат сообщений;
- **PEFT** — `LoraConfig`, `get_peft_model`, число обучаемых параметров, сохранение, загрузка, `merge_and_unload`;
- **TRL** — `SFTTrainer` с потерями только на ответе, `DPOTrainer` на парах «выбранный / отклонённый ответ»;
- **bitsandbytes и Accelerate** — QLoRA (выполняется только на GPU NVIDIA) и `accelerate launch`.

## Запуск

Python 3.10–3.12, `pip install -r requirements.txt`. GPU не нужен: на обычном ноутбуке семинар проходит
за 10–20 минут, на GPU или Apple Silicon — за несколько минут. В ноутбуке явно выключен `bf16`:
по умолчанию TRL его включает, а на CPU он работает в десятки раз медленнее.
