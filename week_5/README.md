плотного поиска с подбором на dev и оценкой на test, модель-судья для соответствия ответа источникам

## Запуск

Python 3.10–3.12, `pip install -r requirements.txt`. Поиск (BM25, multilingual-E5) работает на CPU за
несколько минут. Генерация по умолчанию идёт через OpenAI-совместимый API, как на семинаре week_2
(`NLP_API_BASE_URL`, `OPENAI_API_KEY`, `NLP_API_MODEL`), поэтому GPU не нужен. Локальная модель
`Qwen/Qwen2.5-1.5B-Instruct` (`NLP_BACKEND=local`) — только с видеокартой или на Apple Silicon.
